# 마음도사 챗봇 시험 페이지 (chat-test1)

외상심리건강연구소 마음곁 앱의 챗봇 화면을 웹페이지로 옮긴 시험판입니다. 앱의 "마음도사와 대화하기" 버튼이 이 페이지를 엽니다.

- 주소: http://chat-test1.skkcounsel.kr
- 연구소 챗봇(Flowise)이 아직 http 라서, 이 페이지도 http 로 띄웁니다(https 페이지에서는 브라우저가 http 호출을 막습니다). 챗봇 서버가 https 가 되면 함께 https 로 옮깁니다.
- 비밀값은 없습니다. 대화 id(`?c=`)는 마음곁 서버가 만든 무작위 값입니다.
